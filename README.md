# Alowyy1 Bio

Это исходники моей личной страницы: https://alowyy1.com

Сайт статический и работает на HTML, CSS и JavaScript без сборки.

## Что есть на сайте

- ссылки на мои соцсети
- музыкальный/видео плеер
- статус Discord через Lanyard API
- счётчик просмотров профиля

## Структура

- `index.html` - разметка
- `style.css` - стили
- `script.js` - логика
- `assets/` - картинки, иконки, музыка и курсоры

## Безопасность

В репозитории нет скрытого или обфусцированного кода.
Сайт не содержит форм входа и не собирает пароли.

Внешние запросы:
- `fonts.googleapis.com` и `fonts.gstatic.com` (шрифты)
- `api.lanyard.rest` (статус Discord)
- `/api/bio/views` и `/api/bio/views/hit` (счётчик просмотров)
